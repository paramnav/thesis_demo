Shapley values for feature attribution

A trained model prediction at cell x is decomposed into baseline plus feature contributions (thesis Eq. 1.35): f(x) = E[f(X)] + φ₁(x) + φ₂(x). This demo uses a tiny 2-feature TOC surrogate and exact Shapley values for d = 2 (four coalitions).

Toy model: f(depth, temp) = 12 − 0.004·depth + 0.08·temp (wt.% TOC)

Background expectation E[f] is computed by averaging f over 400 synthetic grid cells (marginal SHAP: absent features sampled from background).
