Interactive Experiments

Companion interactive visualizations for the dissertation on mapping Total Organic Carbon (TOC) and Mass Accumulation Rates (MAR). Data source for this build: synthetic shelf-to-deep-sea transect.

  • CART split threshold
    1D regression tree: slide threshold $t$; watch variance reduction $\Delta$ (Eq. 1.24)
  • Experiment 1a — Random forest
    max_depth & n_estimators dropdowns, outlier scenarios, 3D + 2D maps; toggle to 1D extrapolation
  • Experiment 1b — $k$-NN
    $k$ dropdown, outlier scenarios, 3D + 2D maps; toggle to 1D extrapolation
  • Experiment 1c — MLP
    Layers, architecture, BN, dropout, loss, batch size dropdowns; toggle to 1D extrapolation
  • Information gain
    Experiment 1 MLP + MC dropout σ_MC; prior IG map; toggle hypothetical new cores for surprise
  • Shapley values
    Experiment 1 transect: spatial φ₁/φ₂ maps, click or slide to inspect Eq. 1.35 decomposition

To use your Baltic CSV, copy data_config.example.json to data_config.json, set csv_path, and run python build_experiments.py again.
